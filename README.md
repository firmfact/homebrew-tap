# firmfact/tap

Homebrew tap for the [firmfact](https://firmfact.com/) command-line interface.

```bash
brew install firmfact/tap/firmfact
```

That taps this repository and installs the `firmfact` CLI. Upgrade with
`brew upgrade firmfact`. More ways to install: https://firmfact.com/cli

The cask in `Casks/` is written automatically by the release workflow of
[firmfact/cli](https://github.com/firmfact/cli); please open issues and pull
requests there.
